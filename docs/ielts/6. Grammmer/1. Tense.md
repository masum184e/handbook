**Abbreviations**

- S = Subject
- O = Object
- V1 = Base form (write)
- V2 = Past form (wrote)
- V3 = Past participle (written)
- V-ing = Verb + ing (writing)

Note: The passive structures are used when the verb takes an object and a passive construction is natural.
