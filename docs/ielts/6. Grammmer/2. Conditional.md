## Structures and Examples

| Conditional Type | Structure | Example |
|---|---|---|
| Zero Conditional | If + Present Simple + Present Simple | If you heat water to 100 degrees Celsius, it boils. |
| First Conditional | If + Present Simple + Future Simple | If it rains, they will not play. |
| Second Conditional (a) | If + Past Simple + would/could/might + V1 (present form) | If I won the lottery, I would build a house with the money. |
| Second Conditional (b) | If + were + would/could/might + V1 (present form) | If I were a bird, I would fly to you. |
| Third Conditional (a) | If + Past Perfect + would/could/might + have + V3 (past participle) | If I had seen him, I would have given him the message. |
| Third Conditional (b) | Had + Subject + V3 + would/could/might + have + V3 | Had I seen him, I would have given him the message. |

## Probability and Time

| Probability | Conditional | Example | Time |
|---|---|---|---|
| Certain | Zero Conditional | If you heat water to 100 degrees Celsius, it boils. | Any time |
| Likely | First Conditional | If it rains, they will not play. | Future |
| Unlikely | Second Conditional | If I won the lottery, I would build a house with the money. | Future |
| Impossible | Second Conditional | If I were a bird, I would fly to you. | Present |
| Impossible | Third Conditional | If I had seen him, I would have given him the message. | Past |

Note: `V1` means the base form of a verb, while `V3` means its past participle form.
