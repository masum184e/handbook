Transformer

A Transformer is a deep learning architecture designed to process sequences (like text, audio, or time-series data) using a mechanism called self-attention. It was introduced in the 2017 paper:

Attention Is All You Need

Transformers became the foundation of modern AI systems such as:

  • OpenAI’s GPT models
  • Google’s BERT
  • Image transformers in computer vision
  • Speech and translation systems

Why Transformers Were Created​

Before Transformers, sequence tasks mostly used:

  • RNNs (Recurrent Neural Networks)
  • LSTMs (Long Short-Term Memory)

These models processed words one-by-one, which caused problems:

ProblemExplanation
Slow trainingCannot fully parallelize
Long-term memory issuesEarlier words may be forgotten
Gradient problemsVanishing/exploding gradients
Hard to capture distant relationshipsContext weakens over time

Transformers solved this using:

  • Attention
  • Parallel processing
  • Better long-range dependency handling

Core Idea of Transformers​

The Transformer allows every word to look at every other word directly using:

Self-Attention​

Example sentence:

“The cat sat on the mat because it was tired.”

To understand “it”, the model must know whether it refers to:

  • cat
  • mat

Self-attention helps the model learn that “it” → “cat”.

High-Level Transformer Architecture​

A full Transformer contains:

Input → Encoder → Decoder → Output

Used in tasks like translation:

English → Transformer → French

Main Components​

The Transformer has two major parts:

PartPurpose
EncoderUnderstands input
DecoderGenerates output

Encoder Structure​

Each encoder layer contains:

  1. Multi-Head Self-Attention
  2. Feed Forward Neural Network
  3. Residual Connections
  4. Layer Normalization

Usually stacked many times:

Encoder Layer × N

Self-Attention Explained​

This is the MOST important idea.

For each word, the model computes:

  • Query (Q)
  • Key (K)
  • Value (V)

These are learned vectors.

Intuition​

Imagine reading a sentence:

“The animal didn’t cross the street because it was too tired.”

When processing “it”, attention checks:

  • Which earlier words are important?
  • Which word matches context best?

The model assigns scores.

Attention Formula​

The central formula is:

Attention(Q,K,V)=softmax(QKTdk)V\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)VAttention(Q,K,V)=softmax(dk​​QKT​)V

Where:

SymbolMeaning
QQuery
KKey
VValue
dkd_kdk​Dimension size

1. Similarity Score​

Compute:

QKTQK^TQKT

This measures how related two words are.

2. Scale​

Divide by:

dk\sqrt{d_k}dk​​

This stabilizes training.

3. Softmax​

Convert scores into probabilities.

WordAttention Score
animal0.7
street0.1
tired0.2

4. Weighted Sum​

Combine values based on importance.

Multi-Head Attention​

Instead of one attention calculation, Transformers use many:

Head 1 → Grammar
Head 2 → Meaning
Head 3 → Relationships

This allows learning different patterns simultaneously.

Positional Encoding​

Transformers process words in parallel.

But then:

How does the model know word order?

Solution:

Positional Encoding​

Adds position information to embeddings.

WordPosition
I1
love2
AI3

Formula​

Sinusoidal encoding:

PE(pos,2i)=sin⁡(pos100002i/d)PE_{(pos,2i)}=\sin\left(\frac{pos}{10000^{2i/d}}\right)PE(pos,2i)​=sin(100002i/dpos​)

and

PE(pos,2i+1)=cos⁡(pos100002i/d)PE_{(pos,2i+1)}=\cos\left(\frac{pos}{10000^{2i/d}}\right)PE(pos,2i+1)​=cos(100002i/dpos​)

Feed Forward Network (FFN)​

After attention, each token passes through a neural network:

Linear → ReLU → Linear

This helps learn complex transformations.

Residual Connections​

Transformers use skip connections:

Output = Layer(x) + x

Benefits:

  • Easier gradient flow
  • Stable deep training

Layer Normalization​

Normalizes activations to stabilize training.

Helps:

  • Faster convergence
  • Better optimization

Decoder​

The decoder generates output tokens one-by-one.

It contains:

  1. Masked Self-Attention
  2. Encoder-Decoder Attention
  3. Feed Forward Layers

Why Masking?​

During training: The model should NOT see future words.

"I love deep ..."

It cannot peek at the next word.

Full Flow Example​

Let’s translate:

"I love cats"

to French:

"J'aime les chats"

1. Input Embedding​

Words become vectors:

"I"     → [0.2, 0.1, ...]
"love"  → [0.5, 0.9, ...]
"cats"  → [0.8, 0.3, ...]

2. Add Positional Encoding​

Now order information is included.

3. Encoder Attention​

The word “love” may attend strongly to:

  • “I”
  • “cats”

to understand context.

4. Decoder Starts​

Decoder receives:

<START>

Predicts:

"J'"

Next:

"J'aime"

Then:

"les"

Then:

"chats"

Sentence:

"The bank approved the loan because it trusted John."

WordAttention

The model learns:

"it" → bank

Training Process​

Transformers are trained using:

Backpropagation​

Loss function compares:

  • predicted words
  • actual words

Optimizer updates weights.

Common optimizer:

  • Adam

Complexity​

Self-attention complexity:

O(n2)O(n^2)O(n2)

because every word compares with every other word.

This becomes expensive for long sequences.

BERT

BERT stands for Bidirectional Encoder Representations from Transformers. It is a deep learning language model introduced by Google AI researchers in 2018

BERT changed Natural Language Processing (NLP) because it could understand language contextually and bidirectionally.

Why BERT Was Important​

Before BERT, many NLP models read text:

  • left → right OR
  • right → left

Example:

"The bank of the river"

To understand “bank,” we need both:

  • previous words
  • future words

BERT reads:

left + right context simultaneously

This made language understanding much better.

Core Idea of BERT​

BERT is based on the Transformer Encoder architecture.

Unlike GPT:

BERTEncoder

Transformer Encoder Stack

Bidirectional Understanding​

Traditional Left-to-Right​

A left-to-right model sees only earlier words.

BERT​

BERT sees:

  • words before
  • words after

So it understands:

"it" → animal

more accurately.

BERT uses two major training tasks.

Masked Language Modeling (MLM)​

Why MLM Works​

The model learns:

  • grammar
  • semantics
  • contextual meaning

using both left and right context.

Next Sentence Prediction (NSP)​

BERT learns sentence relationships.

Example​

Sentence A:

"I love machine learning."

Sentence B:

"It is very interesting."

Label:

IsNext = True

Random sentence:

"Bananas are yellow."

Label:

IsNext = False

BERT Training Process​

Steps:

  1. Massive text corpus
  2. Mask random words
  3. Predict masked tokens
  4. Predict sentence relationships
  5. Update weights using backpropagation

Datasets used originally:

  • BooksCorpus
  • English Wikipedia

GPT

GPT stands for Generative Pre-trained Transformer

GPT is a family of deep learning language models designed mainly for:

  • text generation
  • conversation
  • summarization
  • coding
  • reasoning
  • question answering

GPT models are developed by:

  • OpenAI

GPT is based on the Transformer Decoder architecture.

Why GPT Was Created​

Earlier NLP systems had limitations:

ProblemExplanation
Weak context understandingLimited memory
Task-specific trainingNeeded separate models
Poor text generationUnnatural outputs

GPT solved this using:

  • massive pretraining
  • Transformer attention
  • autoregressive generation

Core Idea of GPT​

GPT learns language by predicting:

“What comes next?”​

"The cat sat on the ..."

GPT predicts:

"mat"

After predicting “mat”:

"The cat sat on the mat"

then predicts the next word again.

This process continues repeatedly.

GPT uses a triangular mask.

Visual idea:

Token 1 → can see itself
Token 2 → can see 1,2
Token 3 → can see 1,2,3

Future tokens are hidden.

Repeated many times.

GPT Training Objective​

GPT learns using:

Next Token Prediction​

Input:

Mathematical Objective​

GPT minimizes prediction loss using cross-entropy.

Goal:

Meaning:

Probability of current word given previous words.
